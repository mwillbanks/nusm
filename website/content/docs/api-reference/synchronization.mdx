## `createBroadcastChannelSyncSource`

```ts
function createBroadcastChannelSyncSource<TState = unknown>(
  options: BroadcastChannelSyncSourceOptions,
): NusmSyncSource<TState>
```

<auto-type-table path="../../../../src/sync/broadcastChannel.ts" name="BroadcastChannelSyncSourceOptions" />

`key` must be a non-extractable HMAC-SHA-256 `CryptoKey` with `sign` and
`verify` usage, or at least 32 random bytes for runtime import. `namespace`
and every store `storeId` contribute to an opaque channel capability. The
optional limits can only reduce the built-in protocol maxima.
