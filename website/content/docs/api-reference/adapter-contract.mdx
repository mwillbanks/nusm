## NusmPacerConfig

```ts
type NusmPacerConfig =
  | false
  | {
      wait?: number
      maxWait?: number
      leading?: boolean
      trailing?: boolean
    }
```

`false` bypasses the debouncer. The current runtime forwards `wait`, `leading`, and `trailing` to the `AsyncDebouncer`; `maxWait` remains in the public type but is not forwarded yet.
